# Taller de ciencia participativa (FISABIO)

`Taller-Ciencia-Participativa-FISABIO.html` es la pieza interactiva del taller, en **un solo archivo** (HTML + CSS + JS + fuentes inline; sin peticiones externas).

## Cómo abrirla

- Descarga el archivo y ábrelo con el navegador. No necesita servidor.
- En GitHub puedes usar **Download raw file** (el enlace `raw` no lo renderiza).
- Para compartir por enlace: GitHub Pages, o alojamiento estático. En la web de FISABIO debe ir en el mismo dominio (su CSP bloquea iframes externos).

## Controles

- Caminar: `A` / `D` o flechas.
- Saltar: `Espacio`, `W` o `↑`.
- Abrir la estación más cercana: `Enter` (o el botón «Abrir»).
- La estación 03 exige subir a la estantería; el carro y el humo se saltan.
- En móvil, controles en pantalla.
